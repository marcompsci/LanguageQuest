# Apple compliance report: Language Quest

Audit date: November 12, 2026 · App version 0.7.0 (1) · Commit after `a584206`
Guidelines used: Apple App Review Guidelines, last updated October 16, 2026 (adds 2.3.14 creative assets and 2.5.19 hidden, dormant, or undocumented features, and requires Review Notes to describe new features with specificity under 2.3.1(a)). Also the age-rating system with 4+, 9+, 13+, 16+ and 18+ (new questions required since January 31, 2026; new content descriptors from November 16, 2026), and App Store Connect TestFlight requirements.

> This report is not a guarantee of approval. Apple decides at review time.

## 1. Architecture summary (verified in the repo)

| Area | What exists |
|---|---|
| Stack | Native iOS app. SwiftUI and SpriteKit (`App/`), plus a first-party Swift package `LQCore` (`Packages/LQCore`) for all game and learning logic. XcodeGen spec `project.yml` generates `LanguageQuest.xcodeproj`. |
| Not present | React Native, Expo, Flutter, web views, Firebase, Supabase, any backend, sign-in, accounts, analytics, ads, third-party SDKs or packages, networking code, push notifications, deep links or universal links, entitlements files, CI before this audit. |
| Targets | `LanguageQuest` (iPhone and iPad, iOS 17.0+), `LanguageQuestUITests`. |
| Identity | Bundle id `com.phoronomics.languagequest`, team `X6LZQ3FS36`, automatic signing, category Education. |
| Data | One versioned JSON save in Application Support (file protection: complete until first unlock), with a backup copy. The parent PIN is a salted SHA-256 hash in the Keychain; if it's forgotten, the device passcode or Face ID / Touch ID (LocalAuthentication) can reset it. Nothing leaves the device. |
| Permissions | Microphone and Speech Recognition, only after a parent enables speech practice behind the parental gate. Recognition is on-device only (`requiresOnDeviceRecognition = true`). The microphone listens after the player taps the talk button, until they tap "I'm done" or stop speaking. Face ID is used only by the parent PIN reset. |
| On-device ML | Vision text recognition reads Write Out handwriting in memory. Nothing is stored. |
| Payments | StoreKit 2 code for a proposed "Family Plus" subscription exists, but `StoreConfig.default.paidPlansEnabled == false`. No purchase UI is reachable and no products load. |
| Content | 13 bundled language courses (JSON) generated by `tools/content-authoring/*.py`, written by the dev team, not yet reviewed by native speakers. |
| Audience | Ages 11+ (bands 11–12, 13–15, 16+). Not planned for the Kids Category. |
